Unzip and open index.html in a browser. Select home or enter for objects.html.

## Typing and sound
The index requests typing sound automatically. Browser autoplay rules may keep audio suspended until the first click or keypress. The sound off control appears only after the loading screen and mutes immediately. Turning sound back on replays the typed notes. Audio is generated locally with Web Audio; no external audio files, network requests or tracking. The first click or keypress unlocks audio if the browser requires a user gesture.

A small dependency-free typing.js script now handles character-by-character timing, punctuation pauses, pause controls and optional audio. This update intentionally adds JavaScript for synchronized sound; the existing HTML/CSS presentation remains the fallback if scripts are disabled.

The objects header types once. Chapter labels, image captions and the Japanese footer type as they enter view, then remain readable. Retype replays the footer. Pause text motion pauses pending typing; reduced-motion displays full text. Static accessible text is retained separately from the animated characters.
